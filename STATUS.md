STATUS — AI for Journaling Beginner Manual
============================================

## What Was Built

A beginner-friendly manual on journaling with AI, published as a static HTML
site from Markdown sources. Created by Asdale Dynamics, LLC (Dylan Asdale,
registered nurse turned AI author, Indiana, formed Oct 2026).

**Content areas covered:**
- Getting Started — how AI journaling works, local vs cloud options, first entry
- Privacy Rules — data protection, local-first, no health advice from AI
- Reflection Prompts — daily, weekly, monthly prompts + AI-generated workflow
- Mood Tracking — word-based mood logs, pattern spotting, AI-enhanced review
- Organizing Entries — tagging, naming, search strategies, digital vs paper
- Turning Notes into Insights — themes, mood-activity connections, action steps
- Printable Templates — daily journal, mood tracker, weekly review, reflection cards, insight worksheet

**Project files:**
- `docs/*.md` — 8 Markdown source pages
- `site/*.html` — 8 generated static HTML pages
- `templates/*.html` — 5 printable journal templates
- `templates/printable.css` — print-focused stylesheet
- `assets/style.css` — site stylesheet
- `build.py` — static site generator + built-in test suite
- `Makefile` — build/test/clean/serve shortcuts
- `LICENSE` — MIT License
- `README.md` — project overview with Asdale Dynamics credit
- `AGENTS.md` — build & test guide
- `STATUS.md` — this file

## How to Run It

### Build the static site

```bash
python3 build.py
```

This converts all `docs/*.md` files into `site/*.html` using the Python
`markdown` module and copies `templates/` into `site/templates/`.

### Run verification tests

```bash
make test
```

or equivalently:

```bash
python3 build.py --test
```

### Serve locally

```bash
make serve
```

or:

```bash
python3 -m http.server 8000 --directory site/
```

Then open `http://localhost:8000/` in your browser.

### Clean generated files

```bash
make clean
```

## Known Gaps

- The site is static HTML only — no search functionality beyond browser Ctrl+F
- Templates are HTML/CSS (printable from browser), not PDF — users print via browser
- No automated CI/CD pipeline (intentionally: no `.github/workflows` per project rules)
- `site/` output is committed for convenience but regenerated by `build.py`
- No JavaScript interactivity — intentional for simplicity, privacy, and printability
